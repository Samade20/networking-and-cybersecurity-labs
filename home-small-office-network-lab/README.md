# Configure a Home/Small Office Network

## Project Overview

This lab demonstrates how to configure a home or small office network using Cisco Packet Tracer. The network includes wired and wireless client devices connected through a wireless router, cable modem, ISP, and external servers.

## Objective

To build and understand a small office or home network that allows local devices to communicate with one another and access external services such as DNS, web, and file servers.

## Network Topology

The network includes:

- Desktop PC
- Laptop
- NetPrinter
- Wireless Router
- Cable Modem
- ISP
- File Server
- HQ Web Server
- DNS Server

## Tasks Performed

- Connected wired and wireless devices to the network
- Connected the wireless router to the cable modem
- Connected the modem to the ISP
- Observed the relationship between client devices and external servers
- Built a mixed wired/wireless network topology

## Skills Demonstrated

- Small office network design
- Wireless and wired device integration
- Router and modem connectivity
- ISP-based internet access setup
- Understanding service-based network architecture

## Outcome

The lab successfully demonstrated how a home or small office network can connect local devices to shared internet services such as DNS, file servers, and web servers.
