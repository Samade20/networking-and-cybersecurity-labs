# Create a LAN

## Project Overview

This lab demonstrates how to create a simple Local Area Network (LAN) for a branch office using Cisco Packet Tracer. The goal was to connect end devices through a switch and provide connectivity to an office router and external network resources.

## Objective

To build a basic LAN that connects multiple devices within a branch office and enables communication through a router to an internet-based server.

## Network Topology

The network includes:

- Office Router
- Switch
- Admin PC
- Manager PC
- Printer
- Internet cloud
- Remote web server

## Tasks Performed

- Connected end devices to the switch
- Connected the switch to the office router
- Connected the router to the internet cloud
- Verified internal LAN structure
- Simulated connectivity to an external web resource

## Skills Demonstrated

- LAN design
- Basic device interconnection
- Switch-based network setup
- Router-to-internet connectivity
- Network topology planning

## Outcome

The lab successfully demonstrated how a simple office LAN can be created to connect internal devices and provide access to external network resources.
