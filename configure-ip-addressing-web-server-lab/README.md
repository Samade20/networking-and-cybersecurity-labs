# Configure IP Addressing to Reach a Web Server

## Project Overview

This lab demonstrates how to configure a PC with the correct IP addressing information so that it can communicate with a remote web server in Cisco Packet Tracer.

## Objective

To manually configure IP settings on a client PC, including IP address, subnet mask, default gateway, and DNS information, so that the PC can access a remote web server.

## Network Topology

The network includes:

- PC0
- Office Switch
- Office Router
- ISP Cloud
- DNS Server
- Web Server

## Tasks Performed

- Identified the required LAN addressing range
- Configured the PC with the correct IP address
- Configured subnet mask
- Configured default gateway
- Configured DNS server address
- Tested web access to the remote server

## Skills Demonstrated

- Manual IP configuration
- Default gateway setup
- DNS configuration
- End-to-end connectivity testing
- Troubleshooting network access

## Outcome

The PC was successfully configured with the required addressing information and was able to access the remote web server.
