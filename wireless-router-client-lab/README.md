# Wireless Router and Client Configuration Lab

## Project Overview
This lab demonstrates how to connect a wireless router and a client device in Cisco Packet Tracer. The objective was to simulate a simple home wireless network and verify that the client could successfully connect to the router and access external network resources.

## Objective
To configure a wireless router and connect a client device to the wireless network in a simulated home environment.

## Network Components
- Cable Modem
- Wireless Router
- Client PC
- Internet Cloud
- Web Server
- Cable Splitter

## Tasks Performed
- Connected the cable modem to the internet source
- Connected the wireless router to the modem
- Configured the wireless router
- Connected the client PC to the wireless network
- Verified connectivity between the client and external resources

## Skills Demonstrated
- Wireless router setup
- Client-to-router connectivity
- Basic home network design
- Network simulation using Cisco Packet Tracer
- Connectivity verification

## Outcome
The client device was successfully connected to the wireless router and the simulated network provided access to external internet resources.

## Files in this Project
- `wireless-router-client.pkt` – Cisco Packet Tracer lab file
- `topology.png` – Screenshot of the network topology
- `notes.pdf` – Optional supporting notes

## Why This Project Matters
This lab helped me understand how wireless devices connect within a home network and how routers provide access to external networks. It also strengthened my practical networking foundation for cybersecurity learning.
