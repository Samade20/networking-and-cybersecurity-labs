# Observe Traffic Flow in a Routed Network

## Project Overview

This lab demonstrates how network traffic flows through a routed network using Cisco Packet Tracer. The goal was to observe how packets move between devices and across routers to reach a remote server.

## Objective

To analyze how routers forward packets across networks and how traffic flows from a client device to a server through multiple network devices.

## Network Topology

The network includes:

- PC0
- Switch0
- Router0
- Router1
- Switch1
- Server0

## Tasks Performed

- Built a routed network topology
- Simulated packet flow between PC0 and Server0
- Observed TCP and ARP events in simulation mode
- Analyzed packet forwarding through routers
- Inspected the event list for protocol activity

## Skills Demonstrated

- Routed network analysis
- Packet flow observation
- TCP communication analysis
- ARP process analysis
- Simulation-based troubleshooting

## Outcome

The lab successfully demonstrated how traffic flows through a routed network and how routers process packets between source and destination devices.
