Title: Wireless Router and Client Configuration Lab

Student/Author: Sam Adeniyi

Tool Used: Cisco Packet Tracer

Lab Summary:
This lab focused on connecting a wireless router and a client device in a simulated home network environment. The network included a cable modem, wireless router, client PC, internet cloud, and remote server.

Objectives:

Set up a wireless router

Connect a client device to the wireless network

Verify successful connectivity

Key Concepts Practiced:

Wireless network setup

Router-client communication

Basic network topology

Internet access simulation

Outcome:
The client device successfully connected to the wireless router and could communicate across the simulated network.
