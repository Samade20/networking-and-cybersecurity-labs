# DHCP Configuration on a Wireless Router

## Project Overview

This lab demonstrates how to configure DHCP on a wireless router using Cisco Packet Tracer. The goal was to allow multiple client devices to automatically obtain IP addresses from the router.

## Objective

To configure a wireless router as a DHCP server and allow connected PCs to automatically receive IP addresses and network settings.

## Network Topology

The network consists of:

- 1 DHCP Enabled Wireless Router
- 3 Client PCs (PC0, PC1, PC2)

All devices are connected directly to the router.

## Tasks Performed

- Connected three PCs to the wireless router
- Enabled DHCP on the router
- Configured the router to automatically assign IP addresses
- Set the client PCs to obtain IP addresses automatically
- Verified that each PC received an IP address from the DHCP server

## Skills Demonstrated

- DHCP configuration
- Router configuration
- Client network configuration
- Automatic IP address assignment
- Basic LAN setup

## Outcome

All PCs successfully received IP addresses from the router's DHCP service and were able to communicate within the network.
