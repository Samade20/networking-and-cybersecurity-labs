# Determine Default Gateway for PC Connectivity

## Project Overview

This lab demonstrates how to determine the correct default gateway address required for a client PC to communicate with a remote web server.

## Objective

To identify and configure the correct default gateway for PC0 so that it can communicate outside its local network and reach a remote web server.

## Network Topology

The network includes:

- PC0
- Office Switch
- Office Router
- ISP Cloud
- Web Server

## Tasks Performed

- Inspected router interface information
- Determined the correct gateway address for the local network
- Identified the interface connected to the LAN
- Applied the correct gateway logic to client configuration

## Skills Demonstrated

- Default gateway identification
- Router interface analysis
- Basic routing concepts
- Local-to-remote connectivity understanding

## Outcome

The lab demonstrated how the default gateway serves as the path for traffic leaving the local network and how to determine the correct gateway for a host device.
